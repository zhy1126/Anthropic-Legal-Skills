# Anthropic Legal Skills 中文 README 设计

## 目标

为仓库中的 12 个 Skill 各增加一份面向虞律团队成员的实用型中文 `README.md`。README 帮助律师快速判断是否适用、准备输入、理解输出和正确调用；原始 `SKILL.md` 保持不变，继续作为 Agent 执行指令。

## 固定结构

每份 README 统一包含：

1. 中文名称及英文 Skill 标识；
2. 功能定位；
3. 适用场景；
4. 不适用场景；
5. 使用前需要准备的输入；
6. 预期输出；
7. 本地 Codex 调用示例；
8. 简化工作流程；
9. 律师必须确认的事项；
10. 兼容性与本地化提示；
11. 原始 `SKILL.md` 链接。

## 内容原则

- 使用简明中文重新组织信息，不逐句翻译原文。
- 每份 README 必须与对应 `SKILL.md` 的触发条件、流程、输出和限制一致。
- 明确区分“辅助整理”和“法律判断”，不得把原始美国法口径表述为中国法结论。
- 涉及申报、签署、交割确认、董事会行动或正式对外成果时，必须写明律师或有权人员复核节点。
- Claude 专用路径、配置和集成只作为兼容性提示，不宣称已完成 Codex 或中国法本地化。

## 仓库入口

根目录 `README.md` 的 Skill 表格将增加“中文说明”链接，使团队可以直接进入各 Skill 的中文文档；原始 Skill 链接同时保留。

## 验收标准

- 12 个 Skill 目录均存在 `README.md`；
- 每份 README 都包含固定栏目、正确的 `$skill-name` 调用和有效的 `SKILL.md` 相对链接；
- 12 份原始 `SKILL.md` 未被修改；
- 根 README 能链接到全部 12 份中文说明；
- 仓库中不新增客户资料、访问凭证或未经核验的适用法结论。
