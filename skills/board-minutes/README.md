# 董事会及委员会会议纪要（`board-minutes`）

## 功能定位

依据团队既有会议纪要范本、会议议程、演示材料和实际会议记录，起草董事会或专门委员会会议纪要初稿。核心目标是复用团队的结构、讨论深度和决议语言，减少格式整理工作，同时保留清晰的事实核对清单。

## 适用场景

- 董事会、审计委员会、薪酬委员会或其他委员会会议纪要；
- 会议前根据议程和材料搭建纪要框架；
- 会议后根据记录和演示材料整理完整初稿；
- 需要保持既有长篇叙述式、行动式或混合式纪要风格。

如需起草以书面决议代替会议的文件，应改用 `written-consent`。

## 不适用场景

- 没有既有范本，却希望直接生成可采用的通用格式纪要；
- 缺少实际出席、表决或讨论信息，并要求模型自行补齐；
- 需要判断董事会决议是否合法充分，或替代适用法、章程及议事规则分析；
- 需要模型代为分发、采用或归档正式纪要。

## 使用前准备

- 已批准的既有会议纪要范本或 5–6 份历史纪要；
- 公司、会议类型、日期、时间、地点或线上平台；
- 董事、管理层、顾问及其他来宾的实际出席情况；
- 会议议程、董事会材料、演示文稿及会议记录；
- 章程、议事规则、委员会授权和法定人数要求；
- 实际通过的决议文字、表决结果、回避及利益冲突情况。

## 预期输出

- 按团队格式起草的完整会议纪要初稿；
- 议程项目、讨论摘要、决议、表决和附件引用；
- 对缺失事实使用明确占位符，不虚构会议内容；
- 出席、法定人数、表决、冲突、附件及散会时间核对表；
- 采用前应删除的律师复核提示。

## 调用方式

本地 Codex：

```text
$board-minutes
请根据批准的历史纪要格式、会议议程和会议记录，起草本次董事会会议纪要初稿；缺失事实请保留明确占位符。
```

原始 Claude 插件命令为 `/corporate-legal:board-minutes`。

## 工作流程

1. 确认会议类型、时间、地点、通知方式和主席、秘书；
2. 核对董事实际出席、缺席、管理层及顾问列席情况；
3. 依据章程和适用法核验法定人数；如不足，应停止并提示补救；
4. 从议程和材料提取议题、拟决议事项、演示内容和附件；
5. 严格按照既有范本的结构、讨论深度和决议措辞起草；
6. 对没有来源的讨论内容保留占位符，不作推测；
7. 输出初稿及采用前核对表，由律师和公司秘书审定。

## 律师确认事项

- 通知、法定人数、表决门槛及委员会权限是否符合适用法和公司文件；
- 纪要是否准确反映实际讨论、表决、回避和异议；
- 决议文字是否与会议实际批准内容完全一致；
- 是否需要单列执行会议、特权事项或利益冲突记录；
- 正式采用前所有占位符是否关闭，附件是否齐全。

在律师确认前，只能将成果标记为“供律师审阅的草稿”，不得作为已采用的正式公司记录。

## 兼容性与本地化

原 Skill 假设已在 Claude 配置中保存会议纪要范本、董事会组成和日历连接。本地 Codex 使用时需要重新指定这些来源。原文以美国公司治理语境为主；中国公司、红筹架构或其他法域应按当地公司法、章程和议事规则重做权限、通知、表决及文件形式核验。
