# 主体合规事项跟踪（`entity-compliance`）

## 功能定位

从主体清单建立结构化合规台账，跟踪各主体、各法域的年度报告、特许经营税、信息申报、存续状态和良好存续证明，并生成近期截止日期报告、健康检查和表格导出。

## 适用场景

- 根据组织架构或主体清单初始化合规台账；
- 查询未来 30、60、90 或 180 天到期事项；
- 录入注册代理报告、已申报日期、费用和良好存续状态；
- 批量核对未知、逾期和长期未确认的主体；
- 识别休眠主体、境外资格、主体信息和集团内部协议缺口；
- 向财务、法务运营或注册代理导出 CSV 或表格。

## 不适用场景

- 代替注册代理、主管机关或当地律师提供最新法定期限；
- 代为提交年度报告、税费申报或良好存续证明申请；
- 仅凭州或国家名称推断期限，而未确认主体类型；
- 独立判断某地是否构成需要外州登记或境外登记的经营活动；
- 处理复杂多国主体时替代专业实体管理系统。

## 使用前准备

- 主体名称、主体类型、设立日期、设立法域和运营状态；
- 境内外登记或经营资格清单；
- 注册代理、当地代理及其最新合规报告；
- 上次申报日期、费用、截止日和良好存续证明；
- 公司运营足迹、休眠主体和集团内部协议信息；
- 适用主管机关或官方登记系统的当前规则。

## 预期输出

- 主体 × 法域 × 申报类型的合规台账；
- 逾期、近期到期、已申报、未知和当地代理管理事项；
- 主体健康检查、休眠主体和良好存续缺口；
- 人工更新、注册代理报告导入和逐项清理结果；
- 安全转义后的 CSV 或 Markdown 表格。

## 调用方式

本地 Codex：

```text
$entity-compliance --report --days 90
请根据最新主体台账列出未来 90 天到期、已经逾期和状态未知的事项，并标出需要向注册代理确认的项目。
```

常用模式还包括 `--init`、`--update`、`--sweep`、`--audit` 和 `--export`。原始 Claude 插件命令为 `/corporate-legal:entity-compliance`。

## 工作流程

1. 从团队主体表加载每个主体的类型、法域和注册代理；
2. 优先使用主管机关或注册代理的当前资料确认具体申报要求；
3. 将无法确认的期限标记为 `unknown`，不从旧表或记忆中补齐；
4. 建立或更新合规台账，并计算逾期和近期到期状态；
5. 根据需要生成报告、逐项清理、健康检查或导出文件；
6. 对注册代理报告中的近似主体名称和未匹配项目要求人工确认。

## 律师确认事项

- 主体类型是否准确；同一法域的公司、有限责任公司和合伙企业可能适用完全不同规则；
- 截止日期、费用和申报内容是否经当前官方来源或注册代理确认；
- 正式申报所载董事、高管、地址和代理信息是否真实；
- 是否需要境外登记、注销、合并或其他主体重组行动；
- 在记录“已申报”或确认合规前，是否取得正式回执或其他证明。

## 兼容性与本地化

原 Skill 的示例和部分期限以美国州法为主，台账路径位于 Claude 配置目录。中国及其他法域应建立独立的主体类型、年报、税务、受益所有人、外汇、行业许可和存续要求；所有期限以主管机关和专业顾问的当前信息为准。导出含外部输入时应继续执行公式注入和 CSV 转义防护。
