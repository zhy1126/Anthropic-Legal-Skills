# 项目与团队配置访谈（`cold-start-interview`）

## 功能定位

通过结构化访谈建立团队级法律工作画像，或者为一项新交易建立项目级上下文。访谈把适用业务模块、重要性门槛、既有范本、升级路径、系统连接和交付偏好写入配置，使后续 Skill 按团队真实工作方式运行。

## 适用场景

- 第一次安装并配置整套 corporate-legal Skills；
- 配置文件仍有占位符，或需要全面重新访谈；
- 只新增或更新 M&A、董事会、公众公司或主体管理模块；
- 启动一项新交易，建立交易代号、立场、资料室、负责人和项目门槛；
- 重新检查文件、资料室、日历或协作工具连接是否真正可用。

## 不适用场景

- 直接完成某一份尽调、会议纪要或交易文件；
- 从用户未明确提供的历史对话、个人记忆或其他项目中自动填充客户信息；
- 把默认值当成团队已经批准的法律立场；
- 未经核验便把“已配置”的连接标记为“已成功接通”。

## 使用前准备

- 使用者身份、执业场景、适用法域和内部升级路径；
- 团队业务模块及主要工作类型；
- 已批准的尽调清单、历史问题备忘录和重要性门槛；
- 历史会议纪要、书面决议、披露清单等范本；
- 主体清单、组织架构、注册代理或合规报告；
- 资料室、文档库、日历、协作工具和法律检索工具的实际连接状态；
- 新交易的代号、立场、交易各方、资料室、时间表和负责人。

## 预期输出

- 团队级工作画像和启用模块清单；
- 重要性门槛、问题清单格式、纪要及决议格式等偏好；
- 已验证连接、未验证连接和人工替代方案；
- 新交易的项目上下文文件；
- 明确标记的默认值、待补材料和后续配置事项。

## 调用方式

本地 Codex：

```text
$cold-start-interview
请为虞律团队进行完整配置访谈，先确认适用模块，再读取我们明确提供的范本和项目规则。
```

常见指令还包括：

```text
$cold-start-interview --new-deal
$cold-start-interview --check-integrations
$cold-start-interview --module m&a
$cold-start-interview --redo
```

原始 Claude 插件命令为 `/corporate-legal:cold-start-interview`。

## 工作流程

1. 检查是否首次配置、暂停状态、待补占位符或已有完整配置；
2. 确认使用者身份、执业场景和连接工具的真实可用状态；
3. 选择 M&A、董事会、公众公司和主体管理中的适用模块；
4. 读取用户明确提供的政策、范本和历史成果，减少重复问答；
5. 访谈团队门槛、格式、升级路径、交付节奏和职责分工；
6. 将确认信息写入团队配置；新交易另写项目级上下文；
7. 对默认值、缺失范本和未经核验事实作显著标记，供后续补齐。

## 律师确认事项

- 哪些模块和默认值真正适用于团队；
- 重要性门槛、风险分级和升级路径是否已经获得内部批准；
- 历史范本能否用于当前客户及当前事项；
- 输入材料是否可以用于训练团队配置，是否涉及跨客户信息；
- 用户提供的法条、期限、阈值和法域信息是否经过当前来源核验。

## 兼容性与本地化

原 Skill 的配置目标是 `~/.claude/.../CLAUDE.md`，并假设使用 Claude 插件命令和部分美国公众公司模块。本地 Codex 需要确定新的配置文件位置、连接检测方法和 Skill 调用语法。中国律师团队还应加入利益冲突、客户授权、保密等级、中国法门槛及本所审批要求，不应直接使用原始默认值。
